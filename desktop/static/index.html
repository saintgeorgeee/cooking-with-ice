Come configurare Discord e aggiungere un’attività +

Per iniziare: apri Discord sul computer, poi scegli una carta. Le due animazioni incluse sono già configurate.

Per un nome personale: visita il Discord Developer Portal ↗, crea una nuova applicazione con il nome desiderato e copia il suo Application ID da General Information.

Per un’immagine animata personale: carica il file su un servizio pubblico, come un repository GitHub pubblico, e copia il collegamento diretto HTTPS al file (su GitHub, usa il link raw). Apri Gestisci attività → Nuova attività, inserisci nome, Application ID e URL in Immagini e anteprima → Immagine grande, quindi salva.

Il nome mostrato su Discord è quello della tua applicazione Discord. Premi Turn Off per spegnere la presenza; chiudere l’app la disattiva.
