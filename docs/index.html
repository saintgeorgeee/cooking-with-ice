Getting started

01 — 03
01

Download and unzip

Choose the download for your computer and extract the ZIP file.

02

Open the app

On macOS, open Discord Activity Controller.app. On Windows, open the extracted folder and run Discord Activity Controller.exe.

03

Choose an activity

Open Discord on your computer, then select an activity in the app. Use Turn Off when you want to stop.

The downloads are not signed, so your computer may show a security warning. Only open software you trust. Apple’s guidance for macOS ↗

Add your own

You can add activities with your own Discord Application ID and a public image URL. The app includes a short guide to help you set them up.
